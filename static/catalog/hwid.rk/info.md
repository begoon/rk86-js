Демо «Определение эмулятора» — А. Дёмин, 2026

Проверяет наличие хука Hardware ID (STC×4): четыре подряд "STC"
под эмулятором сбрасывают "CF" и возвращают "A" = ID эмулятора.

Для этого эмулятора A=01, "B" = цветовая схема, "C" = режим «турбо».
Показывает результат и панель FA-байт "80h..0xBF" для текущей цветовой схемы.

В эмуляторе хук по умолчанию выключен в — включите его иконкой «чип» в тулбаре
рядом с «Турбо» или URL-параметром "?hwid=1".

Исходный код программы <a href="https://github.com/begoon/rk86-js/blob/master/static/asm/examples/hwid.asm">hwid.asm</a>.
